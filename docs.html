📖 HABI API — Dokumentasi

Base URL: http://140.245.32.37:3000

1. Daftar API Key

GET /api/register?note=nama-kamu

Response:

{"status":true,"apikey":"HABI-XXXXXXXXXXXX","limit":"25 req/hari"}

2. Info Video

GET /api/info?url=https://youtu.be/xxxx&apikey=KEY

3. Download MP3

GET /api/ytmp3?url=https://youtu.be/xxxx&apikey=KEY

Response: file audio (attachment).

4. Download MP4

GET /api/ytmp4?url=https://youtu.be/xxxx&apikey=KEY

Response: file video MP4 720p (attachment).

Parameter

ParamWajibKet
url✅Link YouTube (youtube.com / youtu.be)
apikey✅Key dari /api/register
note—Nama kamu saat register (opsional)

Error

KodeArti
401APIkey tidak valid
429Limit harian tercapai
500Gagal download (video/private/bot-check)
